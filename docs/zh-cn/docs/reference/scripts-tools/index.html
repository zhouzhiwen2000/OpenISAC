脚本与工具

本页只列出用户需要直接启动的工具。如无特别说明，命令都在仓库根目录执行，并需先安装 requirements.txt 中的 Python 依赖。

如果窗口能打开但没有数据，先检查 YAML 中的感知输出开关、IP/端口和后端日志，而不是重复启动查看器。

OCXO 调试

Section titled “OCXO 调试”

查看器按单位分组显示曲线，保留可配置的滚动历史，并可暂停绘图而不中断接收和 CSV 记录。 通道勾选只影响曲线显示，CSV 始终保存完整的 16 通道数据包。

上行定时控制

Section titled “上行定时控制”

uplink_timing_control.py 通过 BS 和 UE 的 ZMQ 控制端口读取、调整 DUTI 和 TADV 定时值：

远程运行时，将 host 换成 BS/UE 的实际 IP，并确认 network_output.control_port 与命令一致。

CPU 隔离与后端启动

Section titled “CPU 隔离与后端启动”

isolate_cpus.py 从 BS.yaml / UE.yaml 读取关键 CPU 绑定。先应用隔离，再通过 run 启动后端：

默认命令会询问本机角色是 BS、UE 还是 BS+UE。只要存在内核隔离 CPU 就会显示网卡 IRQ 二级菜单；至少有两个可用的隔离物理核心时才显示双队列 RX/TX 分流。run 允许 YAML 关键线程使用指定 CPU，同时会从进程中排除专用网卡 IRQ 核。

网页配置台

Section titled “网页配置台”

浏览器打开 http://127.0.0.1:8765/。该工具编辑当前 build/BS.yaml 和 build/UE.yaml，并提供后端启停与 CPU 隔离操作。具体使用方法见网页配置台。

config_web_editor_schema.yaml、config_web_editor.js 和相关 HTML/CSS 是网页配置台的内部组成文件，不需要单独执行。

文档站

Section titled “文档站”

npm run build 会先生成 site/dist/，再调用 scripts/publish_docs_site.py 更新 docs/。不要直接修改 docs/ 下的生成 HTML。

感知物理坐标

Section titled “感知物理坐标”

fast viewer 和 backend sensing viewer 的 Doppler 坐标统一显示 Hz。单站频谱显示距离（m），双站频谱显示相对时延（ns）；微多普勒时间轴显示秒。检测器参数和 bin 选择控件仍以 bin 索引配置。

后端与 viewer 必须一同更新：仅接收 V9 PARM 参数包，旧版本或未知格式将被拒绝。后端提供原始 OFDM FFT 长度、CP 长度、实际感知符号步长及均匀子载波步长；viewer 使用实际处理 FFT 长度（包括补零）换算坐标。显示裁剪或降采样不会改变物理标定。非均匀 compact 子载波集合不存在统一的 FFT-bin 时延比例，此时明确显示物理时延不可用。

设采样率为 FsF_sFs​，OFDM FFT 长度为 NNN，CP 长度为 NCPN_{CP}NCP​，符号步长为 StS_tSt​，子载波步长为 SfS_fSf​，处理 FFT 长度为 NR,NDN_R,N_DNR​,ND​：

fslow=Fs(N+NCP)St,ΔfD=fslowND,Δτ=NFsSfNR.f_{slow}=\frac{F_s}{(N+N_{CP})S_t},\quad \Delta f_D=\frac{f_{slow}}{N_D},\quad \Delta\tau=\frac{N}{F_s S_f N_R}.fslow​=(N+NCP​)St​Fs​​,ΔfD​=ND​fslow​​,Δτ=Fs​Sf​NR​N​.

单站按 R=cτ/2R=c\tau/2R=cτ/2 换算距离；双站按 109τ10^9\tau109τ 显示 ns，零点相对于当前同步／对齐参考，不能当作发射机或接收机到目标的绝对距离。单站零距离也依赖系统时延对齐标定。改变 FFT 长度会改变坐标的 bin 间隔，不会改变波形本身的物理分辨率。

校准工具

Section titled “校准工具”
