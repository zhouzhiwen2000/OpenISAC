感知界面操作指南

适用界面：scripts/plot_sensing_fast.py 与 scripts/plot_bi_sensing_fast.py。本页对应 2026 年 10 月 15 日的界面，面向具有雷达、无线通信或信号处理基础的实验用户。

两个界面用于连接已经运行的 OpenISAC 系统，查看距离或时延与多普勒谱、观察微动、提取目标，并调整感知与射频参数。

截图由当前界面代码离线生成，谱图与读数采用示例数据。

启动与连接

Section titled “启动与连接”

先启动对应 BS/UE 后端并启用感知输出，再在项目根目录运行需要的界面：

若环境中的 Python 命令名为 python3，相应替换即可。同机运行时填写 127.0.0.1；异机运行时填写后端电脑的 IP。

控件或操作作用与使用方法
Backend IP + Connect输入运行 BS 或 UE 的电脑地址，点击后连接或重新连接。地址框按回车也会连接。等待状态和谱图更新后开始观察。
分区标题前的箭头展开或收起 Display & View、Delay Estimation、Target Detection、Clustering、Alignment、Hardware & RF、Processing Toggles。已启用的功能在分区收起后继续工作。
主窗口关闭按钮退出查看器并关闭目标窗口。独立运行的 BS/UE 后端继续运行。

界面会记住多项输入和开关。连接或后端重连成功后，会恢复保存的 MTI、STRD 等控制；单站还会下发保存的增益。连接前核对增益，尤其是在射频直连校准时。

主谱图

Section titled “主谱图”

Range-Doppler Spectrum 展示距离或时延与多普勒的联合分布。亮点表示较强谱响应；开启检测后，圆点标记提取出的目标位置。零多普勒附近通常包含静态反射、直达泄漏和低速目标。多普勒正负号对应频移方向，运动方向结合实验几何判断。

单击主谱图可用叉号标记观察位置。微多普勒的观察单元通过 Range Bin 单独设置。

微多普勒图

Section titled “微多普勒图”

Micro-Doppler Spectrum 展示选定距离单元的多普勒随时间变化。横轴为时间，单位 s；纵轴为多普勒频率，单位 Hz。可用于观察人体摆臂、肢体运动和旋转等引起的微动特征。目标跨越距离单元时，需要重新选择观察位置。

FFT 图的色标采用当前感知谱的 dB 尺度，适合比较谱分量的相对强弱。MUSIC/CAPON 使用相对伪谱尺度，适合比较峰的位置和分离情况。

状态栏

Section titled “状态栏”
状态含义与用途
Display当前显示的数据来源。
FPS界面刷新速率，用于判断画面流畅程度。
Queue待处理或待显示的数据积压情况。持续积压且画面延迟时，可降低本地处理负担。
Sender、Status数据来源、连接及接收状态。
Params当前数据和处理参数摘要，连接或修改 STRD 后可据此核对。
MD Buffer微多普勒历史数据的积累程度。切换距离单元后重新积累。
Detector当前检测方法、开关和结果摘要。

较长的状态文字可悬停查看完整提示。设备控制执行情况结合新数据、参数回报及后端日志确认。

显示与观察范围

Section titled “显示与观察范围”

Display & View 控制观察单元、处理网格、显示范围和色标。修改输入后，点击所在行的 Set 或 Apply。

控件或按钮作用使用要点
Range Bin + Set选择微多普勒观察的距离或时延单元，索引从 0 开始。先确定目标位置，再选择单元。应用后清空微多普勒历史，等待重新积累。
Delay FFT + Set设置查看器的距离或时延变换长度。增加补零长度可细化谱网格，便于读峰值，同时增加计算量。物理距离分辨率由有效带宽等条件决定。有效长度至少覆盖输入数据。
Doppler FFT + Set设置多普勒变换长度。较大的补零长度细化频率网格；实际多普勒分辨能力由相干观测时间等条件决定。
Delay View + Set设置从零起显示的距离或时延 bin 数量。可集中观察近端区域或扩展范围；本地目标列表也限于当前观察范围。必要时，Range Bin 随范围缩小而调整。
Doppler View + Set设置零多普勒附近的显示 bin 数量。缩小便于观察低速目标，扩大可观察更大的频移范围；本地目标输出随范围变化。
Delay Doppler dB 的 Min、Max + Apply调整主谱图颜色上下限。降低下限可显示更弱的背景；降低上限可让弱谱值更亮。主要用于 FFT 模式，超分辨方法采用自身色标。
MicroDoppler dB 的 Min、Max + Apply独立调整微多普勒图的颜色上下限。用于突出弱微动纹理。颜色下限应小于上限。

色标调整作用于显示。目标检出强弱通过检测参数调整，接收信号幅度通过 RX 增益调整。

bin 与距离、时延和频率

Section titled “bin 与距离、时延和频率”

图轴显示 m、ns、Hz；输入框中的 bin 表示离散网格索引。改变 FFT 长度后，相同索引对应的物理位置会变化，观察目标时应重新核对。

双站 FFT 谱图当前每 2 个距离和多普勒单元显示一个点；Range Bin 按完整距离网格选择微多普勒单元。例如目标列表显示 R=40 时，对应微多普勒单元可从 Range Bin=80 查找。单站默认按完整网格显示。图轴的物理单位已经包含换算。

调整 FFT 长度和显示范围后，感知结果与微多普勒历史会重新建立，等待新数据稳定后继续观察。

感知处理开关

Section titled “感知处理开关”

Processing Toggles 集中控制微多普勒、动目标显示和窗函数。MTI 和两个窗函数以绿色表示开启。

按钮开启后的作用适用场景
Micro-Doppler: ON/OFF开启或停止微多普勒历史积累和计算。人体或机械微动观察时开启；仅查看主谱图时可关闭以减少计算。关闭后保留的图像是之前的结果。
MTI控制后端动目标显示处理，抑制静态或缓慢变化的背景。运动目标检测时有助于压低静态杂波；研究静止反射、直达路径或低速运动时，对比关闭后的结果。
Range Window对距离处理启用 Hamming 窗，降低距离旁瓣。适合强回波旁瓣影响弱回波观察的场景。加窗同时使主瓣展宽，调节时兼顾邻近目标分离。
Doppler Window对多普勒处理启用 Hamming 窗，降低频谱泄漏与多普勒旁瓣。适合观察较弱的运动分量，同时需要考虑主瓣展宽。

选择 FFT 下的 CLEAN 后，两个 Window 按钮会自动关闭并禁用。切回 OS-CFAR 后可按需重新开启。

目标检测

Section titled “目标检测”

检测方法与开关

Section titled “检测方法与开关”
控件或按钮作用与使用方法
Local Detector 下拉框在 OS-CFAR 和 CLEAN 之间选择本地检测方法，选择后立即切换。
Local OS-CFAR: ON/OFF开启或关闭 OS-CFAR 检测。开启后根据局部背景估计门限，并输出目标标记和列表。
Local CLEAN: ON/OFF选择 CLEAN 后，同一开关显示此名称。开启后逐步提取强目标并扣除其响应，寻找剩余分量。
Apply OS-CFAR应用当前 OS-CFAR 参数。应用后确认检测开关为 ON。
Apply CLEAN应用当前 CLEAN 参数。应用后确认检测开关为 ON。

OS-CFAR 适合依据局部噪声与杂波水平提取显著回波；CLEAN 适合检查强目标及其旁瓣影响下的其他分量。目标标记表示当前帧中的候选散射目标，需结合位置、稳定性和实验场景判断。

单站切换到 MUSIC 等非 FFT 方法后，由相应方法直接给出目标，普通检测控件随之隐藏；切回 FFT 后恢复。

OS-CFAR 参数

Section titled “OS-CFAR 参数”

D 表示多普勒方向，R 表示距离或时延方向；窗口尺寸以当前检测网格的 bin 为单位。

参数含义调整效果
Rank(%)对参考单元功率排序后，用于估计背景的分位位置。其余设置相同时，提高该值通常会提高背景估计和门限，使检测更保守。
Train D、Train R多普勒、距离方向的参考区域宽度。小窗口更易受局部波动影响，大窗口可能包含其他目标或不同杂波区域。
Guard D、Guard R目标附近保护区域的半宽，保护区内的数据从背景估计中排除。通常应覆盖目标主瓣附近区域，降低目标能量对背景估计的影响。
Supp D、Supp R接受一个峰后，抑制其周围重复报告的半宽。增大可减少重复点，也可能压掉相邻真实目标；同时联动 DBSCAN 邻域。
Alpha(dB)在估计背景之上增加的门限偏移。增大可减少弱点和虚警；减小会提高对弱目标的敏感度。
Min R目标搜索的最小距离单元索引。用于排除近端泄漏或无兴趣区域。
Min P(dB)候选点需达到的最低谱强度。采用当前界面的谱值尺度，和局部自适应门限共同限制目标输出。
DC Excl零多普勒附近排除区域的半宽。0 表示保留该区域。增大可减少静态残留点，同时减少静止和低速目标的检出。

通常先调整 Alpha(dB) 和 Min P(dB)，获得稳定目标，再依据旁瓣宽度与目标间隔调整保护、抑制和参考区域。谱图边界附近需要足够的参考单元。

CLEAN 参数

Section titled “CLEAN 参数”

参数含义调整效果
Loop Gain每轮扣除所选目标响应的比例，范围为 0.001～1。较小值留下更多残余响应，可能产生邻近候选分量；较大值扣除更充分，对模型误差更敏感。
Max Targets一次处理最多提取的目标分量数。根据场景复杂度设置提取上限。
Min R排除低于该索引的近端距离单元。用于避开泄漏等强分量。
Min P(dB)剩余峰低于该强度时停止提取。降低可提取更多弱分量，也可能增加噪声或残留旁瓣。
DC Excl零多普勒附近的排除区域半宽。观察静态目标时设为 0，并对比关闭 MTI 后的结果。

两种检测方法共用 Min R 与 DC Excl 的当前限制，切换方法后核对这两项。

目标聚类

Section titled “目标聚类”

Clustering 用于整理 OS-CFAR 检测点。一个散射目标可能产生多个相邻点，聚类将它们合并成目标条目，减少重复报告。

控件或按钮作用与使用方法
DBSCAN Eps显示多普勒和距离方向的聚类邻域大小，分别为 Supp D + 1、Supp R + 1。通过调整 OS-CFAR 的抑制范围并应用来改变。
MinPts + Apply DBSCAN设置形成有效密集区域所需的邻近检测点数。增大有助于剔除孤立点，也可能减少弱目标；1 允许单点形成目标。

DBSCAN 作用于 OS-CFAR 结果。CLEAN 和超分辨方法直接输出目标；选择超分辨方法后，聚类控件隐藏。

单站时延估计

Section titled “单站时延估计”

Delay Estimation 改变距离或时延方向的估计方法，用于比较相邻路径或目标的分离表现。

Delay Estimator 选项结果形式与用途
FFT常规距离与多普勒谱，适合建立基线、观察整体场景，并配合 OS-CFAR 或 CLEAN。
MUSIC显示时延伪谱及峰值，适合检查相邻路径；结果受信噪比、数据条件和模型误差影响。
CAPON显示自适应时延谱，用于比较邻近分量的分离情况与干扰影响。
ROOTMUSIC直接输出时延候选点，以目标点和列表作为主要结果。
ESPRIT直接估计时延候选点，可与 FFT、MUSIC 结果交叉比较。

Peak Rel(dB) + Apply 设置相对于本次最强峰的候选峰保留门限。例如 -12 保留最强峰以下约 12 dB 范围内的候选峰；改为 -6 更严格，改为 -20 会保留更多弱峰。

切换方法后等待重新计算。比较超分辨结果时，结合已知目标位置、峰值稳定性和 FFT 基线评估。

时延对齐

Section titled “时延对齐”

Alignment 调整感知时延参考。输入单位为原始信号的采样点数，所有按钮按增量执行。

按钮作用
Delay + Apply将输入的有符号整数作为本次对齐增量。例如输入 10 并点击两次，累计执行两次 +10。
+57600正向调整 57600 个采样点，用于较大偏差的粗调。
-57600反向调整 57600 个采样点。
+10正向调整 10 个采样点。
-10反向调整 10 个采样点。
+1正向调整 1 个采样点，用于细调。
-1反向调整 1 个采样点。

单站调整感知接收的对齐量；双站叠加 UE 感知的人工时延修正。先选一个清晰参考峰，用 +1 或 -1 观察变化方向，再选择合适步长。

对齐直接影响距离或时延参考。记录最终对齐条件，并通过系统配置保存适用的标定值，有助于复现实验。

系统控制与校准

Section titled “系统控制与校准”

采样步长和增益

Section titled “采样步长和增益”

控件或按钮作用使用要点
STRD + Set设置感知慢时间采样的 OFDM 符号间隔。同等采样点数下，较大步长覆盖更长时间，但会降低慢时间采样率、缩小无模糊多普勒范围；较小步长适合较快运动。
Frame every N + Set每 N 个完整感知帧处理并输出 1 帧；1 表示全部输出。保留帧内 STRD 和无模糊多普勒范围；降低刷新率和后级负载。单站快速上位机保留滚动历史并按缺失时间补零；需要连续观测时使用 1。
TX Gain(dB) + Set修改 BS 发射增益，单站界面提供。会改变实际发射信号，同时影响感知回波和通信链路。
RX Gain(dB) + Set修改单站感知接收增益。按信号强弱调整，兼顾弱目标可见度和接收机线性工作范围。

STRD 可用取值由系统配置决定。采用 compact_mask 资源图样时，采样位置由图样确定，需通过配置调整。修改后以回报参数和日志确认实际设置。双站的 TX/RX 增益在相应 BS/UE 配置中设置。

Hsys 系统响应校准

Section titled “Hsys 系统响应校准”

Calibrate Hsys 请求测量并补偿收发链路的频率响应，减少硬件幅相起伏对感知谱的影响。单站校准其收发链路；双站校准 BS 到 UE 的感知链路。

  1. 先完成系统时延对齐，设置适当的 TX/RX 增益，并准备足够的外部衰减，使接收机保持在线性工作区。
  2. 按校准链路连接发射端与接收端的射频线缆。双站连接 BS 发射与 UE 接收，并运行两端后端。
  3. 点击 Calibrate Hsys，保持接线和增益稳定。
  4. 等待后端日志确认校准完成并保存文件。
  5. 停止相关后端后恢复天线或实验连接，再继续空口测量。

当前运行会使用新校准，后续启动时加载匹配文件。改变增益、线缆或其他射频条件后，重新检查校准适用性。Hsys 应在准备好的射频直连条件下执行，完整准备与验证步骤见校准流程。

目标列表

Section titled “目标列表”

OpenISAC Top Targets 窗口按当前帧目标强度排序，最多列出 12 个条目。序号随每帧目标排序更新。

字段含义
R当前显示网格中的距离或时延索引。
rel相对于当前参考起点的距离或时延，有物理参数时使用 m 或 ns。
单站 f_D / v_r，双站 D单站显示频率 Hz 或径向速度 m/s，与图轴一致；双站 D 仍为相对于零多普勒的 bin 索引。
S目标强度，结合所用方法的谱值尺度解释。
N该目标条目包含的检测点数。
C检测点簇中心的距离和多普勒索引。

列表用于检查目标位置、强度及点簇分布。结合谱图观察同一位置附近的结果是否稳定，可以帮助判断阈值与聚类参数是否合适。

数据保存

Section titled “数据保存”

三个按钮分别保存当前的一份数据快照，文件采用 MATLAB .mat 格式，也可用 Python 读取。

按钮保存内容适用用途
Save Raw查看器收到的感知输入帧，通常为复数信道数据，变量名 raw_frame。离线重新处理或比较算法。数据所处的处理阶段随系统输出模式确定。
Save RD当前距离或时延与多普勒显示矩阵，变量名 rd_map。留存当前谱结果，包含显示裁剪和算法效果。ROOTMUSIC/ESPRIT 的主要结果为目标点，点列表需另行记录。
Save MD已积累的微多普勒显示矩阵，变量名 md_map。保存目标微动的时频结果。先确认微多普勒图已更新。

文件写入启动命令所在目录的 capture/，例如 capture/capture_rd_20261015_143000.mat。保存成功路径会显示在终端。

同时记录 FFT 长度、STRD、算法和观察单元等实验条件，便于恢复距离、时延和频率单位并复现实验。文件名时间精度为秒，同一类型的连续保存应间隔至少一秒。若需要对比同一帧数据，应额外核对采集时刻。

典型操作流程

Section titled “典型操作流程”

运动目标观察

Section titled “运动目标观察”
  1. 连接对应 BS 或 UE，确认主谱图持续更新，以 FFT 建立初始观察结果。
  2. 开启 MTI；使用 OS-CFAR 时按需开启两个窗函数，观察旁瓣和主瓣宽度。
  3. 设置 Delay View、Doppler View 和色标，让目标位于清晰可见的范围。
  4. 开启 OS-CFAR，逐步调整 Alpha 与 Min P，再根据重复点调整抑制和聚类。
  5. 查看目标列表的位置、强度和稳定性，保存 RD 并记录参数。

静态路径观察

Section titled “静态路径观察”
  1. 关闭 MTI，将检测器的 DC Excl 设为 0 并应用。
  2. 检查 Min R，使参考路径和近端目标处于搜索范围。
  3. 观察零多普勒附近的谱，逐步开启和调整检测。
  4. 双站实验记录时延补偿方式与人工对齐量，便于比较传播路径变化。

微多普勒观察

Section titled “微多普勒观察”
  1. 从主谱图确定目标所在距离或时延位置。
  2. 将完整距离网格索引填入 Range Bin 并点击 Set；双站按前述比例换算。
  3. 开启 Micro-Doppler，等待历史积累，再调整色标观察微动纹理。
  4. 目标跨越距离单元时重新选择，等待新一段数据建立。
  5. 点击 Save MD，同时记录观察单元、STRD 和采样条件。

单站可选径向速度显示

Section titled “单站可选径向速度显示”

在 plot_sensing_fast.py 的 Display & View 中，将实际发射的射频载频填入 Velocity RF Carrier (GHz)，点击 Set 或按回车。主谱图横轴、微多普勒图纵轴和检测目标列表随即显示径向速度，单位 m/s。清空输入框并应用后，恢复多普勒频率 Hz。已应用的值会自动保存，下次启动继续使用。

换算关系为 vr=fDc/(2fc)v_r = f_D c / (2 f_c)vr​=fD​c/(2fc​)，正负号沿用图中的多普勒频率。使用外接毫米波变频器时，应填写变频后的实际射频载频，而非 USRP 中频；例如只有实际射频为 77 GHz 时才填 77。该设置仅用于显示换算，不改变设备调谐、FFT 运算、检测门限或 bin 坐标。正负速度对应的实际运动方向需结合变频器的频谱方向和实验约定确认。双站界面保持多普勒频率显示，因为不能直接套用单站公式换算径向速度。

主谱图右上角以黄色文字单独显示最强检测回波的距离及速度，保留一位小数；载频留空时显示多普勒频率。信息框位置与尺寸固定，没有检出目标时数值显示 N/A。

单站快速上位机在丢帧或帧抽取时保留微多普勒滚动历史，按缺失的慢时间位置补零。这样可保留真实时间间隔，但不能恢复缺失回波，空档仍可能降低谱峰或引入旁瓣。改变距离单元、采样几何或时间戳回退时，历史重新建立。
